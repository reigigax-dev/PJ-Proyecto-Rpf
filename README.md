## REQUISITOS (para utilizar la funcion de scaneo de carnet)

> ### Minimos
> - Equipo con `Windows 10`.
> - Webcam (preferiblemente de buena calidad).
> - Programa `Tesseract OCR` instalado.
>
> ### Recomendado
> - Equipo con `Windows 10` con acceso a internet.
> - Aplicacion `Enlace Movil` instalada en el equipo.
> - Programa `Tesseract OCR` instalado.
> - Celular (con acceso a internet).

## INSTALACIONES / PASO A PASO

> ### Instalacion del programa Tesseract (ubicado en la carpeta `APPS`)
> 1. Ejecutar el instalador (al popu de permisos de administrador seleccionar la opcion `SI`).
> 2. En la opcion de lenguaje seleccionar la opcion `Español (Alfabetización Internacional)`, luego seleccionar la opcion `OK`.
> 3. Selecciona la opcion `Siguiente`.
> 4. Luego selecciona la opcion `Acepto`.
> 5. Selecciona la opcion `Siguiente` nuevamente en la ventana.
> 6. En esta ventana es necesario de seleccionar el recuadro que contiene un mas al lado del texto `additional language data (download)`, esto desplegara una ista de idiomas donde seleccionaremos la opcion o idioma `Spanish`.
> 7. Una vez seleccionado el idioma debes de darle a `Siguiente`.
> 8. Por ultimo en esta ventana deberas de seleccionar la opcion `Siguiente` y luego seleccionar la opcion `Instalar`.
> 9. Una vez termine la instalacion deberas de seleccionar la opcion `Siguiente` y luego Terminar para cerrar el `Instalador`. 

## COMO EJECUTAR EL SISTEMA

> Para ejecutar el sistema una vez este instalado los programas requeridos deberas de solo realizar doble click o abrir el archivo de comandos llamado `iniciar.cmd`
>> Este comando instalara las librerias necesarias para que funcione el sistema y levantara el mismo en una ventana de navegador
>> #### IMPORTANTE: Si quieres utilizar la funcion de escanear carnet es necesario de seleccionar `Permitir` en los permisos de la camara que te solicitara el navegador.

## Como utilizar la Webcam Virtual (`Enlace Movil`)
#### IMPORTATE: Debes de presentar una cuenta de Microsoft para poder utilizar esta aplicacion (debe ser la misma cuenta ingresada tanto en el telefono como en el equipo)

> 1. Para utilizar esta camara virtual deberas de primero ejecutar la aplicacion de `Enlace Movil` en tu equipo (computador)
> 2. Esta aplicacion te solicitara que tipo de telefono utilizas `Android` o `iPhone`.
> 3. Una vez selecciones algunas de las opciones aparecera un codigo QR el cual deberas de escanear con el telefono que deseas asociar.
> 4. Para escanear el codigo QR es necesario de que en el telefono en cuestion tengas instalada la aplicacion `Enlace Movil` o por el contrario `Enlace a Windows`
> 5. En la aplicacion desde el telefono deberas de iniciar sesion con la misma cuenta de Microsoft que esta logeada en la aplicacion de `Enlace Movil` del equipo (computador).
> 6. Una vez iniciada sesion con la misma cuenta deberas de seleccionar la opcion `vincular tu teléfono y tu PC` lo que te permitira escanear el codigo QR para asicioar tu telefono al equipo.
> 7. Por ultimo luego de realizar el escaneo de QR el telefono te soliciatara aceptar los permisos para utilziar las funciones de dicha aplicacion, una vez le des a Permitir el telefono podra tener acceso a las funciones de `Enlace Movil`.

> ### Activar Webcam 
>> Ahora que esta asociado el telefono desde el `Enlace Movil` te indicare como activar el telefono para que funcione como Webcam.
>>
>> 1. Tendras que acceder a la opcion de `Configuracion` de Windows (esto se puede realizar accediendo desde la barra de busqueda desde el simbolo de Windows)
>> 2. Una vez en la configuracion deberas de acceder a `Bluetooth y Dispositivos`, luego deberas de acceder a la opcion de `Dispositivos moviles`
>> 3. Dentro de dispositivos moviles seleccionaras el telefono vinvulado.
>> 4. Una vez seleccionado el telefono vinculado debes de activar la opcion de `Usar como camara conectada`, esto te habilitara por fin de utilizar el telefono como Webcam dandote acceso a escanear los carnet desde la opcion de la aplicacion
>> 5. Cuando accedas a la apliacion el telefono te solicitara permisos para utilizar la camara del telefono, una vez le des permitir veras como en la pantalla se utilizara la camara de tu celular para poder escanear carnets :D
